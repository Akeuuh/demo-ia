# Beyond Context - OpenCode Presentation

Session 3 de la série "Dev with AI" @ TF1

## Installation

```bash
cd sessionThree
npm install
```

## Lancer la présentation

### Mode développement (avec hot reload)

```bash
npm run dev
```

Ouvre automatiquement http://localhost:3030

### Exporter en PDF

```bash
npm run export
```

Génère un fichier `slides-export.pdf`

### Build pour production

```bash
npm run build
```

Génère une version statique dans `dist/`

## Navigation dans Slidev

- **Flèche droite/gauche** : Slide suivante/précédente
- **Espace** : Slide suivante
- **Flèche haut/bas** : Navigation verticale (si applicable)
- **O** : Vue d'ensemble de toutes les slides
- **D** : Mode sombre
- **F** : Plein écran
- **G** : Aller à une slide spécifique
- **C** : Mode caméra (pour enregistrer)

## Fonctionnalités Slidev

- ✅ Hot reload automatique
- ✅ Syntax highlighting pour le code
- ✅ Mode présentateur (notes)
- ✅ Enregistrement de la présentation
- ✅ Export PDF
- ✅ Dessiner sur les slides pendant la présentation

## Fichiers

- `slides.md` : Contenu de la présentation au format Slidev
- `presentation.md` : Version markdown originale (pour référence)
